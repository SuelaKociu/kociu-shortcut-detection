# Changelog

## 2.1.0-candidate - 2026-07-26

- Corrected confirmatory Primary B to compare the combined profile+output detector against the output-only detector.
- Renamed the machine-readable result field to `combined_minus_output_accuracy`.
- Added a regression test and validator check for the prespecified comparator.
- No confirmatory scientific result is introduced by this correction.

## 2.0.0 - 2026-07-21

- Renamed the label-conditioned statistic from Delta-phi to Task-Structured Separability (TSS).
- Replaced universal and impossibility claims with generator-bounded empirical claims.
- Separated archived pilot summaries from prospective confirmatory analyses.
- Added a marginal-matched randomized control, condition-independent scaling, five neutral probes, 50 paired seeds, complete-pair inference, per-network outputs, pair-bootstrap comparisons, and tests.
- Added a symmetric sparse generator while preserving the historical generator only in `legacy/`.
- Added a frozen-detector transfer run with generator-specific reliance interventions, checkpoint losses, and environment/source manifests.
- Added manuscript, bibliography, Zenodo metadata, dual licensing, CI, and an AI-assistance disclosure.

## 1.0.0 - 2026-07-02

- Original exploratory scripts and figures.
